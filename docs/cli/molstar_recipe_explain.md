## molstar recipe explain

Explain how a recipe compiles to a job and scene

```
molstar recipe explain RECIPE [flags]
```

### Options

```
  -h, --help     help for explain
      --json     write JSON report (default true)
      --schema   validate with the recipe JSON Schema before explaining
```
