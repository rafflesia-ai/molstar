## molstar cache explain

Explain the cache key and offline availability for an input

```
molstar cache explain INPUT [flags]
```

### Options

```
      --cache string      cache directory (default ".molstar-cache")
      --format string     input format override
  -h, --help              help for explain
      --json              write JSON report
      --provider string   identifier provider for bare IDs (default "pdbe")
```
