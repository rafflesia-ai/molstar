## molstar job init

Write a starter headless job spec

```
molstar job init [ID_OR_PATH_OR_URL] [flags]
```

### Options

```
      --format string   output format: yaml or json (default "yaml")
  -h, --help            help for init
  -o, --out string      output path; use - for stdout (default "-")
```
