## molstar capabilities

Report renderer, Mol*, Node, canvas, GL, and worker capabilities

```
molstar capabilities [flags]
```

### Options

```
  -h, --help               help for capabilities
      --json               write a machine-readable report to stdout
      --probe-worker       start one renderer worker and request its capabilities
      --timeout duration   capability probe timeout (default 20s)
```
