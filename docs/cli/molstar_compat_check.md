## molstar compat check

Check the local headless job/MVS/render compatibility corpus

```
molstar compat check [flags]
```

### Options

```
  -h, --help             help for check
      --json             write JSON report
      --out-dir string   directory for compatibility artifacts; defaults to a temporary directory
      --render           include the real local render probe
```
