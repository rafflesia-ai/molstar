## molstar install-local

Install this CLI and renderer config onto the local PATH

```
molstar install-local [flags]
```

### Options

```
      --bin-dir string   directory to install the molstar binary into
      --config string    config path; defaults to XDG config or ~/.config/molstar/config.json
      --force            overwrite an existing executable
  -h, --help             help for install-local
      --home string      source checkout/runtime root; auto-detected when omitted
      --json             write a machine-readable report
      --name string      installed executable name (default "molstar")
```
