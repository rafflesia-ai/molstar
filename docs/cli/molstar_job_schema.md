## molstar job schema

Print the JSON Schema for headless job specs

```
molstar job schema [flags]
```

### Options

```
  -h, --help         help for schema
      --info         print schema versioning and compatibility metadata
      --json         write JSON errors if the command fails
  -o, --out string   schema output path; use - for stdout (default "-")
```
