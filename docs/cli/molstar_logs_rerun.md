## molstar logs rerun

Rerun a .molrun bundle without importing it

```
molstar logs rerun BUNDLE [flags]
```

### Options

```
  -h, --help             help for rerun
      --json             write machine-readable output
      --out-dir string   directory for rerun outputs; defaults to original output paths
```
