## molstar update-runtime

Refresh or repair the packaged Node/Mol* renderer runtime

```
molstar update-runtime [flags]
```

### Options

```
      --config string      config path to write; defaults to current/default config
  -h, --help               help for update-runtime
      --home string        runtime root; defaults to configured runtime home
      --json               write a machine-readable report
      --skip-install       only rewrite config and validate existing runtime files
      --timeout duration   capability probe timeout (default 30s)
```
