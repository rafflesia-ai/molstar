## molstar version

Report CLI build and renderer runtime provenance

```
molstar version [flags]
```

### Options

```
  -h, --help               help for version
      --json               write a machine-readable report to stdout
      --skip-runtime       skip Node/Mol* runtime probing
      --timeout duration   runtime probe timeout (default 20s)
```
