## molstar fixtures verify

Verify the fixture corpus end to end

```
molstar fixtures verify [flags]
```

### Options

```
      --dry-run          print the planned fixture set without rendering
      --golden           verify deterministic fixture output metadata and visual hashes
  -h, --help             help for verify
      --json             write JSON report
      --keep-going       continue after a fixture fails
      --network          include public remote fixtures that require network access
      --out-dir string   directory for fixture outputs (default "outputs/fixtures")
```
