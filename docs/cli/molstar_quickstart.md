## molstar quickstart

Verify the local install and render a first demo image

```
molstar quickstart [flags]
```

### Options

```
  -h, --help             help for quickstart
      --json             write machine-readable output
      --open             open the demo image after rendering
      --out string       alias for --out-dir (default "molstar-quickstart")
      --out-dir string   directory for quickstart outputs (default "molstar-quickstart")
```
