## molstar scene validate

Validate a job or MVSJ scene

```
molstar scene validate FILE [flags]
```

### Options

```
  -h, --help                      help for validate
      --json                      write a machine-readable report to stdout
      --no-extra                  treat extra MVS node params as validation issues
      --validate-command string   validator command override
```
