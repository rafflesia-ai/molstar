## molstar job migrate

Migrate a headless job spec to the latest version

```
molstar job migrate INPUT [flags]
```

### Options

```
  -h, --help           help for migrate
      --json           write JSON report
      --write string   migrated job output path; use - for stdout (default "-")
```
