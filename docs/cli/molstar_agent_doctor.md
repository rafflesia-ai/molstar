## molstar agent doctor

Check the machine-readable CLI contract an automation agent can rely on

```
molstar agent doctor [flags]
```

### Options

```
      --deep               also run the heavier self-test
  -h, --help               help for doctor
      --json               write a machine-readable report to stdout
      --keep               keep generated agent doctor artifacts
      --out-dir string     directory for temporary agent doctor artifacts
      --timeout duration   overall agent doctor timeout (default 1m0s)
```
