## molstar logs list

List recent local runs

```
molstar logs list [flags]
```

### Options

```
      --dir string   run history directory; defaults to .molstar-runs or MOLSTAR_RUNS_DIR
      --failed       only list failed runs
  -h, --help         help for list
      --json         write machine-readable output
      --limit int    maximum number of runs to list; 0 means all (default 20)
```
