## molstar completion

Generate shell completion scripts

### Synopsis

Generate shell completion scripts for bash, zsh, fish, powershell, or all shells.

```
molstar completion SHELL [flags]
```

### Options

```
  -h, --help             help for completion
      --out string       write completion script to this file
      --out-dir string   write completion script into this directory
```
