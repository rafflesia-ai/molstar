## molstar logs show

Show a saved local run report

```
molstar logs show RUN_ID [flags]
```

### Options

```
      --dir string       run history directory; defaults to .molstar-runs or MOLSTAR_RUNS_DIR
  -h, --help             help for show
      --json             write machine-readable output
      --last             show the most recent local run
      --open-output      open the first image/video output from the saved report
      --out-dir string   directory for rerun outputs; defaults to original output paths
      --rerun            rerun the saved normalized job or MVS scene
```
